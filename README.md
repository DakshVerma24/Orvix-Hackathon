#NestFind AI - The ultimate PG finding app

This is NestFind, the best app for students for finding PG's, and for PG Owners to promote their PG.

It is based on HTML, CSS, and JavaScript with Python for the backend and SQL for the database. So, it does not need to be downloaded.

Website Link - To be updated soon

Here is how it works - 
1. If the user is a person looking for a PG, they can see all of them near his area. These PG's include safety ratings, availability to nearby facilities and more. We will use AI to make sure that the people he may be staying with are compatible with him, including waking/sleeping time, guests allowed/not allowed, and much more.

2. If the user is a person looking for a roommate in his PG, they can list his PG along with his habits, including smoking, drinking, and much more. We will then send a notification to anyone who has matching habits of that user.

3. If the user is a PG owner, they can list their PG along with documents and photos of available facilities, along with the per month rent. We will then use AI to verify their certificates and the claims.

#Tech Stack
Front End - HTML, CSS, Javascript
Backend - Python
Database - SQL
